# 偏好自动学习改造记录

## 要改什么

- 点选条件页删除固定偏好标签，时长和预算改为数字输入。
- 推荐偏好页改为只读画像，移除“恢复自动学习”和保存按钮。
- 生成请求携带匿名 `sessionId`，生成前读取用户画像。
- 新增 30 天行为聚合器和 `GET /api/user-profile`，画像写入 `wb_user_profiles`。
- 补全确认、收藏、浏览、替换事件的类型、标签、区域和主题信息。

## 怎么学习

- 原始行为长期保留；当前画像使用最近 30 天数据。
- 收藏和确认是强信号，浏览是弱信号，单纯生成只作低权重兜底。
- 标签从路线快照里的真实 POI 数据读取，不从地点名称猜测。
- Supabase 不可用或用户没有历史时返回空画像，不影响路线生成。

## 怎么验证

- 覆盖数字输入解析和范围校验。
- 覆盖行为权重、时间窗口、空用户和数据库失败降级。
- 运行前端测试、Agent 类型检查和生产构建。

建表 SQL 单独保存并由部署者在 Supabase 执行；应用运行时不自动建表。

## 实际改动

- `routeRequest.ts` 和点选页：移除固定偏好，修正数字时长/预算解析与校验。
- `profileLearner.ts`：新增 30 天加权聚合和 Supabase 读写降级。
- `generate-plan`、`user-profile`、`server.mjs`：接入匿名会话画像。
- `tracker.ts` 和推荐偏好页：补充学习信号并改成只读展示。
- `docs/wb-user-profiles.sql`：新增部署用建表 SQL。

验证命令：`npm test`、`npm run build`、`npm run typecheck`。
