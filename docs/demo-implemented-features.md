# WeekendBuddy Demo 已实现功能说明

版本日期：2026-06-06

## 1. 产品主流程

当前 Demo 已实现完整的周末盲盒路线闭环：

1. 用户在首页输入自然语言需求。
2. 用户可选择盲盒类型，也可选择“惊喜盲盒”让 Agent 自动判断。
3. 后端优先用大模型解析用户意图，包括区域、同行人、预算、偏好、时间和限制。
4. Agent 根据盲盒类型与用户需求调用高德地点检索，实时生成候选 POI。
5. 路线生成器把候选 POI 组合成 3-4 个节点的半日路线。
6. 页面展示盲盒主题、路线节点、地图、推荐理由和工具调用结果。
7. 用户可以确认路线、继续换整条路线，或只替换其中一个节点。
8. 用户确认后进入 Agent 预订辅助/加入行程展示页。

## 2. 盲盒类型

首页已支持以下盲盒类型：

- 惊喜盲盒：用户不确定时使用，由 Agent 自动判断路线风格。
- 小众拍照吃货盒：强调拍照、咖啡、美食和小众打卡。
- 夜景微醺盒：适合朋友、情侣，强调晚间活动、夜景、简餐和小酌。
- 雨天室内回血盒：强调室内、雨天可去、解压和稳定执行。
- 亲子轻松放电盒：强调亲子、低强度、少走路。
- 城市散步疗愈盒：强调散步、安静、轻体验和疗愈。
- 省钱快乐盒：强调预算友好、性价比和平价体验。

如果用户在自然语言中提到“晚上、夜景、小酌、微醺、酒吧、精酿、bistro、简餐”等内容，即使没有手动选择，也会倾向匹配到“夜景微醺盒”。

## 3. 大模型作用

当前 Demo 中大模型主要体现在四个环节：

1. 意图解析：把用户一句话拆成城市/区域、人数、预算、偏好、限制、时间。
2. 盲盒风格理解：结合用户输入和盲盒类型决定路线风格。
3. POI 简介生成：基于高德返回的地点名称、分类、区域、商圈和路线主题，为每个节点生成一句 20-35 字的展示简介。
4. 节点替换判断：当用户只替换某一站时，大模型会结合当前路线、用户补充要求和候选 POI 判断替换点。

大模型调用失败时，系统会回退到规则解析和模板简介，保证 Demo 不会卡死。

## 4. 实时地点检索

当前实时检索工具基于高德地点搜索接口，主要用于：

- 首次生成路线。
- 用户继续换整条路线。
- 用户对单个节点不满意并继续刷新替代点。

支持深圳多个区：

- 福田
- 南山
- 罗湖
- 宝安
- 龙岗
- 龙华
- 盐田
- 坪山
- 光明
- 大鹏

如果用户输入“龙岗附近”“盐田区”“光明区”等区域词，Agent 会优先在对应区域检索，而不是固定使用原始 Mock 数据。

## 5. Mock 数据和保底策略

Mock POI 数据仍然保留，作用是保底：

- 高德实时检索失败时使用。
- 大模型意图解析失败时使用规则解析。
- 候选不足时尽量从本地真实 POI 补齐路线。

当前策略不是完全依赖 Mock，也不是完全依赖实时接口，而是：

实时检索优先，Mock 数据兜底。

## 6. 路线生成规则

当前路线生成器已实现：

- 每条路线尽量保持 3-4 个节点。
- 候选足够时至少补足 3 个节点。
- 优先保持同一区域或同一 routeCluster，避免频繁跨区。
- 根据活动类型、预算、人群、偏好、排队和距离打分。
- 对有经纬度的 POI 做简单空间排序，减少绕路。

典型路线结构：

- 玩乐/拍照/文化体验节点
- 咖啡/甜饮/休息节点
- 简餐/正餐节点
- 夜景/散步/收尾节点

## 7. 换路线逻辑

用户点击“不满意，换路线”后：

1. 前端发送 reroll 事件。
2. 后端保留原始硬约束，如区域、人数、预算、盲盒类型。
3. Agent 避开上一条路线的核心节点。
4. 重新调用实时地点检索。
5. 重新生成一条完整路线。
6. 回到路线确认页，而不是直接进入加入行程。

新路线生成后，用户可以继续：

- 继续换路线。
- 继续换节点。
- 确认路线。

## 8. 单点替换逻辑

用户点击“只换一个节点”后：

1. 页面展示当前路线节点。
2. 用户选择某一站。
3. 系统展示当前区域下的替换方向，例如“附近拍照打卡点”“附近室内体验”“附近咖啡甜饮”。
4. 用户确认后，后端实时搜索具体 POI。
5. 大模型判断是否适合替换。
6. 替换成功后仍停留在路线确认页。

如果用户对替换结果仍不满意，点击“再换一个节点”会继续针对刚替换出的节点刷新一个新地点。

## 9. POI 过滤规则

为避免搜索结果太抽象或不可执行，当前已过滤：

- 政府机构
- 道路/路口/地铁站/公交站
- 住宅/公司/银行/医院/学校
- 照相馆
- 摄影服务
- 婚纱摄影
- 写真
- 证件照
- 儿童摄影
- 汉服旅拍

这样可以避免“想找拍照地点”时推荐照相馆、写真馆这类不适合作为周末路线节点的结果。

## 10. 地图能力

Demo 已接入高德地图展示路线：

- 路线节点有经纬度时展示真实地图点位。
- 新路线或节点替换后，地图会基于当前路线节点刷新。
- 地图不可用时会展示备用路线图。

## 11. 预订辅助能力

当前预订辅助是 Mock 能力，不会真实登录美团、下单或声明预订成功。

已实现：

- 判断哪些节点可直接加入行程。
- 对需要预订/确认的节点展示预订辅助信息。
- 展示模拟入口、电话话术、行动建议。
- 明确提示当前版本只模拟预订前的信息整理和入口跳转。

## 12. 首页交互

首页已实现：

- 自然语言输入。
- 盲盒类型选择。
- 大模型配置展示。
- 快捷 chips。
- “试试这样说”随机展示。

“试试这样说”会在每次刷新时从更多样例里随机抽取 4 条，避免每次固定展示同一组话术。
