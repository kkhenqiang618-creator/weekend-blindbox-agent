# Weekend Buddy Demo

This repository contains the Weekend Buddy demo package.

## Structure

- `demo/`: Vite + React frontend demo.
- `new-agent-a-module/`: agent module source, demos, and related docs.

## Frontend Demo

```bash
cd demo
npm install
npm run dev
```

## Agent Module

```bash
cd new-agent-a-module
npm install
npm run demo:agent
```
